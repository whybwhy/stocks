
텔레그램 **그룹 채팅**에 봇을 넣는 방법입니다.

---

### 1. 그룹 만들기(이미 있으면 생략)

- 채팅 목록에서 **새 그룹** 만들기  
- 그룹 이름 정하고, 멤버 추가 후 생성

---

### 2. 봇을 그룹에 추가

1. **그룹 채팅방** 들어가기  
2. 상단 **그룹 이름** 탭  
3. **멤버 추가** 또는 **Add members**  
4. 검색창에 **봇 사용자명** 입력  
   - BotFather에서 만든 봇 이름 (예: `@YourBotName`)  
5. 검색된 봇 선택 → **추가**  
6. (필요하면) 봇에게 **메시지 보내기 권한**이 있는지 확인  
   - 그룹 설정에서 “멤버가 메시지 보낼 수 있음” 등이 막혀 있지 않은지 확인

---

### 3. 그룹 채팅 ID 확인 (알람 받을 때 필요)

봇이 **그룹**에 메시지를 보내려면 **그룹의 chat_id**가 필요합니다.

1. 봇을 그룹에 추가한 뒤, **그룹에서 아무 메시지 1개** 보내기  
2. 브라우저에서 아래 주소 접속 (봇 토큰은 본인 봇 토큰으로 바꾸기):  
   `https://api.telegram.org/bot<봇토큰>/getUpdates`  
3. JSON 결과에서 `"chat": { "id": -100xxxxxxxxxx, "title": "그룹이름", ... }` 찾기  
4. **`id` 값**이 그룹의 chat_id (보통 **음수**, 예: `-1001234567890`)  
5. 이 값을 `application.yml`의 `telegram.chat-ids`에 추가:

```yaml
telegram:
  chat-ids:
    - "8066272092"        # 1:1 채팅
    - "-1001234567890"    # 그룹 채팅 (음수, 따옴표 유지)
```

---

### 요약

| 단계 | 내용 |
|------|------|
| 1 | 그룹 채팅방 열기 |
| 2 | 그룹 이름 탭 → 멤버 추가 |
| 3 | 봇 사용자명(@봇이름) 검색 후 추가 |
| 4 | 그룹에서 메시지 1개 보낸 뒤 `getUpdates`로 그룹 chat_id 확인 |
| 5 | `application.yml`의 `chat-ids`에 그룹 chat_id 추가 |

이렇게 하면 알람이 **1:1 채팅**과 **그룹 채팅** 모두로 전송됩니다.
